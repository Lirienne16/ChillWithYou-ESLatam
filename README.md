# Chill With You — Español Latinoamérica

Mod no oficial de traducción al español latinoamericano realizado por **Susumi**.

## Cómo instalarlo

1. Cierra el juego.
2. Entra en [Releases](https://github.com/Lirienne16/ChillWithYou-ESLatam/releases/latest).
3. Descarga `ChillWithYou_ESLatam_Instalador.exe`.
4. Abre el instalador y selecciona la carpeta del juego si no aparece automáticamente.
5. Haz clic en **Instalar traducción**.

## Actualizaciones

Puedes volver a abrir el mismo instalador después de una actualización del juego. Si existe una versión nueva del mod, el instalador te avisará y podrá descargarla.

## Desinstalación

Abre el instalador y selecciona **Desinstalar** para restaurar los archivos originales.

El mod no modifica tus partidas guardadas.

Proyecto comunitario no afiliado con los desarrolladores ni editores de *Chill With You: Lo-Fi Story*. Se requiere una copia legítima del juego.
